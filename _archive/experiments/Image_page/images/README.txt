📸 照片文件夹使用说明

将你的照片文件放在这个文件夹中。

建议的命名方式：
- photo1.jpg
- photo2.jpg
- photo3.jpg
- ...

支持的图片格式：
- JPG / JPEG
- PNG
- WebP
- GIF

建议的图片尺寸：
- 宽度：800-2000px
- 高度：600-1500px
- 文件大小：< 2MB（以保证加载速度）

提示：
- 横向照片适合占据多列（如 2×1 的网格区域）
- 纵向照片适合占据多行（如 1×2 的网格区域）
- 方形照片最灵活，可以根据需要调整

如果需要使用占位图片测试布局，可以使用：
