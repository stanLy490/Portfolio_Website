# 🎵 背景音乐系统 - 5分钟上手指南（集中配置版）

## ⭐ 新特性：一次修改，全站生效！

现在所有的音乐配置都集中在 **`Audio/musicConfig.js`** 一个文件中。

**不需要**在每个页面单独修改音乐URL，只改一个文件即可！

---

## 第一步：上传你的音乐文件到GitHub

1. 打开你的GitHub仓库 `Image_Bed`
2. 点击 "Upload files"
3. 上传你的音乐文件，比如：
   - `Opening_Ethereal.mp3` - MainPage主题音乐
   - `Galaxy_Theme.mp3` - Galaxy/Meteorite音乐
   - `Ambient_Music.mp3` - 其他音乐

4. 上传后，点击文件，再点击 "Raw" 按钮，复制URL
   - 格式像这样：`https://raw.githubusercontent.com/Shaobo-copilot/Image_Bed/main/Opening_Ethereal.mp3`

---

## 第二步：配置音乐（只需修改一个文件！）

打开文件：**`Audio/musicConfig.js`**

### 📍 配置音乐库（第12-36行）

在 `MusicLibrary` 对象中定义所有音乐：

```javascript
const MusicLibrary = {
    // 主题音乐A - MainPage使用
    mainTheme: {
        name: '主题音乐 - 空灵',
        url: 'https://raw.githubusercontent.com/Shaobo-copilot/Image_Bed/main/Opening_Ethereal.mp3',
        volume: 0.25
    },

    // 主题音乐B - Galaxy/Meteorite使用
    galaxyTheme: {
        name: '银河主题',
        url: 'https://raw.githubusercontent.com/Shaobo-copilot/Image_Bed/main/Galaxy_Theme.mp3', // 🔧 改这里！
        volume: 0.25
    },

    // 添加更多音乐...
};
```

### 📍 配置页面映射（第39-52行）

在 `PageMusicMap` 中指定每个页面使用哪个音乐：

```javascript
const PageMusicMap = {
    // MainPage 文件夹内所有页面使用主题音乐A
    'MainPage/Main.html': 'mainTheme',
    'MainPage/page1.html': 'mainTheme',
    'MainPage/page2.html': 'mainTheme',
    'MainPage/page3.html': 'mainTheme',

    // Galaxy 和 Meteorite 使用主题音乐B
    'Galaxy/web.html': 'galaxyTheme',
    'Meteorite/meteorite.html': 'galaxyTheme',
};
```

## 常见问题 Q&A

### ❓ 如何更换 MainPage 的音乐？
**答：** 打开 `Audio/musicConfig.js`，找到 `mainTheme`，修改 `url` 即可。
- **旧方法**：需要改4个文件（Main.html, page1/2/3.html）
- **新方法**：只改1个文件（musicConfig.js）✅

### ❓ 如何添加新的音乐？
**答：** 在 `MusicLibrary` 中添加新条目：
```javascript
myNewMusic: {
    name: '我的新音乐',
    url: 'https://xxx.mp3',
    volume: 0.3
}
```
然后在 `PageMusicMap` 中指定哪个页面使用它。

### ❓ 如何让多个页面共用一首音乐（无缝切换）？
**答：** 在 `PageMusicMap` 中，把这些页面都映射到同一个音乐键名。例如：
```javascript
'MainPage/page1.html': 'mainTheme',  // 都用mainTheme
'MainPage/page2.html': 'mainTheme',  // 切换时不会中断
```

### ❓ 为什么音乐不播放？
**答：** 浏览器要求用户先交互（点击页面）才能播放音乐。
**解决：** 点击页面任意地方。

### ❓ 音量太大/太小？
**答：** 在 `musicConfig.js` 的 `MusicLibrary` 中修改 `volume` 值：
- `0.1` = 很小声
- `0.25` = 适中（默认）
- `0.5` = 较大声
- `1.0` = 最大声

### ❓ 左下角的音量按钮在哪？
**答：** 打开任意配置了音乐的页面，左下角会自动出现。

### ❓ 如何移除或移动音量按钮？
**答：** 在 `Audio/volumeControl.css` 中修改 `.volume-control-btn` 的 `bottom` 和 `left` 属性。

## 配置示例（使用 musicConfig.js）

### 示例1：全站同一首音乐
```javascript
// 在 musicConfig.js 中：
const MusicLibrary = {
    mainTheme: {
        name: '全站统一音乐',
        url: 'https://xxx/music.mp3',
        volume: 0.25
    }
};

const PageMusicMap = {
    'MainPage/Main.html': 'mainTheme',
    'MainPage/page1.html': 'mainTheme',  // 全部用mainTheme
    'MainPage/page2.html': 'mainTheme',
    'MainPage/page3.html': 'mainTheme',
    'Galaxy/web.html': 'mainTheme',      // Galaxy也用相同音乐
};
```
**效果：** 所有页面切换时音乐一直播放，永不中断

---

### 示例2：MainPage 和 Galaxy 用不同音乐
```javascript
// 在 musicConfig.js 中：
const MusicLibrary = {
    mainTheme: {
        url: 'https://xxx/opening.mp3',
        volume: 0.25
    },
    galaxyTheme: {
        url: 'https://xxx/galaxy.mp3',  // 不同的音乐
        volume: 0.3
    }
};

const PageMusicMap = {
    'MainPage/Main.html': 'mainTheme',
    'MainPage/page1.html': 'mainTheme',
    'MainPage/page2.html': 'mainTheme',
    'MainPage/page3.html': 'mainTheme',
    'Galaxy/web.html': 'galaxyTheme',        // Galaxy用不同音乐
    'Meteorite/xxx.html': 'galaxyTheme',     // Meteorite和Galaxy相同
};
```
**效果：**
- MainPage内切换：不中断
- MainPage → Galaxy：切换到galaxy音乐
- Galaxy → Meteorite：不中断（因为用相同音乐）

## ⚠️ 关于音乐卡顿问题

**现状：** 页面跳转时音乐会有 100-300ms 的短暂卡顿。

**原因：** 每次跳转页面，浏览器会销毁旧页面的音频播放器，新页面重新创建音频播放器并恢复播放进度。即使使用 localStorage 保存状态，音频文件还是需要重新加载。

**解决方案：** 如果需要完全无缝的音乐播放，可以使用容器方案（已提供 `index.html`），将音频播放器放在顶层容器中，所有内容页作为 iframe 加载。但这需要改变页面架构。

**当前方案：** 接受轻微卡顿，使用集中配置管理音乐。对于大多数用户体验来说，这已经足够好了。
