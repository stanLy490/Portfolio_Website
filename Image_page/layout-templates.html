💡 使用提示：
1. 复制你喜欢的模板代码
2. 粘贴到 index.html 中的 <div class="gallery-container"> 里
3. 修改图片路径和文字内容
4. 在浏览器中预览效果
5. 根据需要微调 data-grid-area 的值

🎨 自定义网格大小

如果需要更多列，在 style.css 中修改：

.gallery-container {
    grid-template-columns: repeat(4, 1fr);  /* 从3改为4列 */
    /* 或更精确的控制： */
    grid-template-columns: 300px 1fr 1fr 200px;  /* 4列不同宽度 */
}
